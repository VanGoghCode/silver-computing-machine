# Quality Standards

## Code Quality

- All code must pass linting and formatting checks before commit.
- Tests are required for business logic, security rules, and lifecycle transitions.
- No silent failures — errors must be reported through proper channels.

## Output Quality

- Every deliverable must match the role's output format specification.
- Reviews are mandatory before merging.
- Breaking changes require approval from the Architect or Tech Lead.

## Principles

- Do not guess requirements. Ask upward when blocked.
- Do not silently overwrite context.
- Do not bypass communication permissions.
