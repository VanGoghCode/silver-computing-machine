# No-Assumption Rules

## Core Rule

If something is unclear, ask upstream. Lower roles ask upper roles. CEO/CTO/Product Manager ask the human if needed.

## All Questions Must Be Stored

- Questions are saved as context artifacts.
- Answers are saved as context artifacts.
- Decisions are saved as context artifacts.

## No Guessing

- Do not assume requirements. Ask.
- Do not assume priority. Ask.
- Do not assume acceptance criteria. Ask.
- Do not assume technical decisions. Ask.
- When in doubt, escalate.

## Principles

- Do not guess requirements. Ask upward in the hierarchy when blocked.
- Save important decisions as context artifacts.
- Use only approved context when executing.
- Do not silently overwrite context.
- Do not bypass communication permissions.
